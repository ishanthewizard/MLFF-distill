## MD-computed conductivities (in progress)
`draft/conductivity/calc_all_conductivity.py` computes ionic conductivity
(Onsager + Nernst-Einstein) for every GROMACS production trajectory under
`yuejian/bytemol/production_runs/{npt,nvt}/*` using
`byteff2.md_utils.onsager_conductivity.onsager_calc`.

Per system: parses `.top`/`.itp` for species/masses/charges, `.mdp` for
T_K, loads `.tpr`+`.xtc` with MDAnalysis (unwrap + NoJump for continuous
PBC-unwrapped positions), averages box volume over the trajectory, and
calls `onsager_calc`. Dynamic viscosity is a placeholder (1.0 cP) since it
only affects the Dself_inf finite-size correction, not the conductivity
outputs.

Output: `draft/conductivity/results/conductivity_results.csv` with columns
cation, anion, solvent, concentration, temperature_K, ensemble,
conductivity_onsager_mS_cm, conductivity_NE_mS_cm.

Status: COMPLETE. 36 rows (18 systems x npt/nvt) written to
`draft/conductivity/results/conductivity_results.csv`. Run was
interrupted once partway through (8/32 done at the time) and resumed with
a skip-if-already-done check (matching on cation/anion/solvent/
concentration/ensemble); finished cleanly on resume (exit code 0).

## Parity plot vs experiment (final, 32 matched points)
`draft/conductivity/parity_plot.py` matches MD results to
`draft/ref/cleaned_all_properties/cleaned_data.csv` by
(cation, anion, solvent, concentration) with |T_MD - T_exp| <= 2 K, and
plots MD (Onsager + NE, converted mS/cm -> uS/cm) vs experimental
conductivity (uS/cm) on a log-log parity plot.
Output: `draft/conductivity/results/parity_plot.png` (log-log) and
`draft/conductivity/results/parity_plot_linear.png` (linear axes, 0 to
~1.05x max value), plus `draft/conductivity/results/parity_data.csv` (32
rows). Both plots show MAE/R2 in the legend (Onsager: MAE=4397 uS/cm,
R2=-0.89; Nernst-Einstein: MAE=7580 uS/cm, R2=-6.47).

Note: only the 1.0 M systems (LiPF6/DME 0.5M, NaOTf/DME, NaOTf/DEGDME,
NaPF6/DME, NaPF6/DEGDME, NaPF6/PC, all ~298K) had matching experimental
points within +-2K; the 0.12M and 0.5M-at-273/323K MD systems have no
experimental counterpart in cleaned_data.csv at a matching concentration
or temperature.

Observations:
- NVT generally overestimates conductivity vs experiment (e.g. LiPF6/DME
  0.5M: MD Onsager 20368 vs exp 5676 uS/cm; NaOTf/DME 1.0M: MD 10243 vs
  exp ~1235 uS/cm; NaOTf/DEGDME 1.0M: MD 5280 vs exp ~2790 uS/cm).
- NPT brings several systems much closer to experiment (e.g. NaOTf/DME
  1.0M: MD 6513 vs exp ~1235 - still high but closer; NaPF6/DME 1.0M: MD
  11200 vs exp ~12920 - very close; NaPF6/DEGDME 1.0M: MD 2124 vs exp
  ~6700 - now underestimates).
- NaPF6/PC 1.0M underestimates in both ensembles (MD NPT 1045 vs exp
  ~6500 uS/cm).
- Overall: order-of-magnitude agreement with significant system-dependent
  scatter (both over- and under-estimates), consistent with known
  limitations of classical OPLS-AA force fields for ion transport
  (ion-pairing/mobility errors, finite-size effects, short (20 ns)
  trajectories for slow-diffusing concentrated electrolytes).

## Decisions made (per user direction)
- Used "USE THIS" / corrected IC columns where the source flagged them
  (0.5M KPF6/NaPF6 DME table_02, LiPF6 "IC corrected" column).
- Kept the IC1/T1, IC2/T2, IC3/T3 triplicates as 3 separate rows
  (replicate measurements at slightly different actual temperatures, not
  three different quantities).
- Only kept systems where conductivity AND density/viscosity AND
  diffusivity_solvent (D*_0) are all available. Diffusivity is per-species
  (cation/anion/solvent), so missing cation diffusivity (e.g. K+, Cs+ not
  NMR-measurable) does not exclude a row — left blank instead.
- Temperature scope ended up being ~25C (298.2K) only, since that's the
  only overlap between the conductivity sweeps (25-80C) and the
  density/viscosity/diffusivity table (293.2K, 298.2K).
- G2 = DEGDME, G4 = TEGDME, G1 = DME (per solvent naming in source files).
- Pure-solvent rows (no salt) and systems present in only one dataset
  (e.g. 1.0 M KPF6/DME, 0.1 M NaTFSI in any solvent, 0.5 M NaPF6/KPF6 in
  DME) were excluded.
